---
title: "Shell Completions"
description: "Enable tab completion for the loko CLI in bash, zsh, and fish"
---

`loko` ships built-in shell completion (generated by [Cobra](https://github.com/spf13/cobra)).
It completes commands, sub-commands, and flags out of the box, and — for
arguments that take a workload or environment name — the valid values as well.

Supported shells: **bash**, **zsh**, **fish**.

```bash
loko completion bash    # print the completion script for bash
loko completion zsh
loko completion fish
```

## Install

### bash

Completion needs `bash-completion` installed (`brew install bash-completion@2`
on macOS, `apt install bash-completion` on Debian/Ubuntu).

```bash
# current shell only
source <(loko completion bash)

# persist it
loko completion bash > /usr/local/etc/bash_completion.d/loko              # macOS (Homebrew)
loko completion bash | sudo tee /etc/bash_completion.d/loko > /dev/null   # Linux
```

### zsh

Make sure completion is enabled once in `~/.zshrc`:

```bash
autoload -Uz compinit && compinit
```

Then:

```bash
# current shell only
source <(loko completion zsh)

# persist it — write into a directory on $fpath
loko completion zsh > "${fpath[1]}/_loko"
```

On macOS with Homebrew, `${fpath[1]}` is usually
`/opt/homebrew/share/zsh/site-functions`. Start a new shell afterwards.

### fish

```bash
# current shell only
loko completion fish | source

# persist it
loko completion fish > ~/.config/fish/completions/loko.fish
```

## What gets completed

- Every command and sub-command (`loko wo<TAB>` → `loko workloads`, then
  `loko workloads <TAB>` → `connect deploy disable enable endpoints health`).
- Every flag and, where the flag takes a fixed set of values, those values.
- Workload-name arguments — completed from your `loko.yaml` (for
  `enable` / `disable` / `deploy` / `health` / `connect` / `endpoints`) or
  from the catalog.

Completion reads a local `loko.yaml`, searching up the directory tree from the
current directory. If no config is found, name completion falls back to an
empty list (commands and flags still complete).

## Troubleshooting

**No completions at all** — confirm the script is being sourced:
`type _loko` (zsh) or `complete -p loko` (bash) should print something.

**Commands complete but workload names don't** — you're not in (or below) a
directory containing `loko.yaml`, or the file doesn't parse. Run
`loko config validate`.

**zsh: `command not found: compdef`** — `compinit` hasn't run; add the
`autoload -Uz compinit && compinit` line to `~/.zshrc` above the `source` line.
